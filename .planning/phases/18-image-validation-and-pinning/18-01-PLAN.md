  <action>
Create the NemoClaw workload directory structure mirroring OpenClaw's layout.

1. Create `workloads/nemoclaw/base/kustomization.yaml`:
   - `apiVersion: kustomize.config.k8s.io/v1beta1`
   - `kind: Kustomization`
   - `namespace: nemoclaw`
   - `resources: [statefulset.yaml]`
   - Phase 19 will add service.yaml, configmap.yaml, httproute.yaml, etc. to this list

2. Create `workloads/nemoclaw/base/statefulset.yaml` as a minimal placeholder:
   - `apiVersion: apps/v1`, `kind: StatefulSet`
   - `metadata.name: nemoclaw-sandbox`, `metadata.namespace: nemoclaw`
   - `metadata.labels` and `spec.selector.matchLabels`: `app.kubernetes.io/name: nemoclaw-sandbox`
   - `spec.serviceName: nemoclaw-sandbox`
   - `spec.replicas: 1`
   - Single container: `name: nemoclaw-sandbox`
   - `image: ghcr.io/nvidia/openshell-community/sandboxes/openclaw` (bare name, NO tag -- overlay pins by digest)
   - `imagePullPolicy: IfNotPresent`
   - `resources.requests`: memory 512Mi, cpu 250m
   - `resources.limits`: memory 4Gi, cpu 2000m (larger than OpenClaw due to Python/agent tooling)
   - Add a YAML comment at the top: "Minimal placeholder for Phase 18 image validation. Phase 19 adds: command, ports, probes, volumeMounts, volumes, volumeClaimTemplates, env, initContainers."
   - Do NOT include: command, ports, probes, volumeMounts, volumes, volumeClaimTemplates, env, securityContext. These belong to Phase 19.

3. Create `workloads/nemoclaw/overlays/dev/kustomization.yaml`:
   - `apiVersion: kustomize.config.k8s.io/v1beta1`
   - `kind: Kustomization`
   - `resources: [../../base]`
   - Use the `images:` transformer with the `digest` field (NOT `newTag`):
     ```yaml
     images:
       - name: ghcr.io/nvidia/openshell-community/sandboxes/openclaw
         digest: sha256:9cbcd43828664972ee8839d1b729edbc04149c494d846de4078785991a3e9911
     ```
   - Add inline comment: `# Pinned 2026-03-20 (matches tag: 6daeacd). Update with: make pin-image WORKLOAD=nemoclaw`
   - Do NOT set `newTag` -- when `digest` is set, `newTag` is silently ignored. Use ONLY `digest`.

4. Verify the overlay builds correctly:
   - Run `kubectl kustomize workloads/nemoclaw/overlays/dev`
   - Confirm the output contains `image: ghcr.io/nvidia/openshell-community/sandboxes/openclaw@sha256:9cbcd43828664972ee8839d1b729edbc04149c494d846de4078785991a3e9911`
   - Confirm `namespace: nemoclaw` appears in the rendered output
  </action>
  <verify>
    <automated>kubectl kustomize workloads/nemoclaw/overlays/dev | grep -q '@sha256:9cbcd43828664972ee8839d1b729edbc04149c494d846de4078785991a3e9911' && echo "PASS: digest-pinned image reference" || echo "FAIL: digest not found in kustomize output"</automated>
  </verify>
