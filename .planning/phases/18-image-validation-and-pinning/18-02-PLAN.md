  <name>Task 1: Create scripts/pin-image.sh</name>
  <files>scripts/pin-image.sh</files>
  <action>
Create `scripts/pin-image.sh` -- a generic script that extracts the current image digest from the container registry and updates the workload's overlay kustomization.yaml.

The script must:

1. Accept one argument: the workload name (e.g., `nemoclaw`, `openclaw`)
2. Source `scripts/lib/common.sh` for logging functions
3. Validate the argument is provided, exit with usage message if not
4. Derive paths:
   - `OVERLAY_FILE="workloads/${WORKLOAD}/overlays/dev/kustomization.yaml"`
   - Validate the overlay file exists, exit with error if not
5. Extract the image name from the overlay file:
   - Parse the `name:` field under the `images:` section
   - Use: `grep -A1 'images:' "$OVERLAY_FILE" | grep 'name:' | awk '{print $2}'`
   - If the overlay uses `newTag` instead of `digest` (like OpenClaw), the script should still work -- it reads the image name and computes the digest for informational purposes. For OpenClaw, print the digest but note that the overlay uses `newTag` not `digest`, so the user would need to manually switch to digest pinning.
6. Extract the current digest from the registry using skopeo (primary) or docker (fallback):
   - Primary: `skopeo inspect --raw "docker://${IMAGE_NAME}:latest" | sha256sum | awk '{print "sha256:" $1}'`
   - This computes the manifest index digest (correct for multi-arch images)
   - Fallback if skopeo not found: `docker manifest inspect "${IMAGE_NAME}:latest" | sha256sum | awk '{print "sha256:" $1}'`
   - Note: `docker manifest inspect` may require `docker login` for some registries. GHCR public images should work without auth.
   - If neither tool is available, exit with error: "Neither skopeo nor docker found. Install skopeo: brew install skopeo"
7. Read the old digest from the overlay file:
   - `OLD_DIGEST=$(grep 'digest:' "$OVERLAY_FILE" | awk '{print $2}' || echo "none")`
   - If no `digest:` line exists (e.g., OpenClaw uses `newTag`), print info message and the new digest, then exit 0 (informational mode)
8. Compare old and new digest:
   - If identical: print "Image digest unchanged: ${NEW_DIGEST}" and exit 0
   - If different: update the file
9. Update the overlay file using portable sed:
   - `sed -i.bak "s|digest: ${OLD_DIGEST}|digest: ${NEW_DIGEST}|" "$OVERLAY_FILE"`
   - `rm -f "${OVERLAY_FILE}.bak"` (cleanup backup for macOS/Linux portability)
   - Also update the inline comment date if present: `sed -i.bak "s|# Pinned [0-9-]*|# Pinned $(date +%Y-%m-%d)|" "$OVERLAY_FILE"` then cleanup .bak
10. Print summary:
    - "Old digest: ${OLD_DIGEST}"
    - "New digest: ${NEW_DIGEST}"
    - "Updated: ${OVERLAY_FILE}"
    - "Review the change and commit manually."
11. Exit 0

Script header:
```bash
#!/usr/bin/env bash
# =============================================================================
# scripts/pin-image.sh - Update workload image digest from container registry
# =============================================================================
# Generic script for pinning any workload's image by digest.
# Extracts the manifest index digest (correct for multi-arch images).
#
# Usage:
#   ./scripts/pin-image.sh <workload>
#   make pin-image WORKLOAD=nemoclaw
#
# Dependencies:
#   skopeo (primary) or docker CLI (fallback)
# =============================================================================
set -euo pipefail
```

Make the script executable: `chmod +x scripts/pin-image.sh`

Important constraints per user decisions:
- Pin only -- does NOT load the image into cluster nodes
- Does NOT auto-commit
- Must work for both OpenClaw and NemoClaw (generic)
