Create a new executable bash script at `scripts/verify-networkpolicy.sh` that runtime-verifies NetworkPolicy enforcement on a live KIND cluster. The script codifies the exact 4 manual tests from the Phase 7 verification report (`.planning/phases/07-network-security/07-VERIFICATION.md` "Human Verification Required" section).

**Script structure:**

1. Standard shebang and header comment: "verify-networkpolicy.sh -- Runtime verification of NetworkPolicy enforcement. Requires: Running KIND cluster with OpenClaw deployed and NetworkPolicies applied."

2. `set -euo pipefail`, source `lib/common.sh` from the script's directory.

3. Counters: `PASSED=0`, `FAILED=0`.

4. Helper function `run_test`:
   - Takes two arguments: test name (string) and result (exit code: 0=pass, non-zero=fail)
   - On pass: `log_info "PASS: ${name}"` and increment PASSED
   - On fail: `log_error "FAIL: ${name}"` and increment FAILED

5. Pre-flight checks (abort if any fail):
   - Cluster exists: `kind get clusters 2>/dev/null | grep -q "^openclaw-dev$"` -- if not, `log_error "KIND cluster 'openclaw-dev' not found"` and exit 1.
   - OpenClaw pod ready: `kubectl get pod -n openclaw -l app.kubernetes.io/name=openclaw-gateway --field-selector=status.phase=Running -o name 2>/dev/null | head -1` -- if empty, log error and exit 1.
   - NetworkPolicies exist: `kubectl get networkpolicy -n openclaw --no-headers 2>/dev/null | wc -l` -- if less than 2, log error and exit 1.

6. Determine the pod name: `POD=$(kubectl get pod -n openclaw -l app.kubernetes.io/name=openclaw-gateway -o jsonpath='{.items[0].metadata.name}')`.

7. **Test 1: DNS resolution.** Execute via `kubectl exec -n openclaw ${POD} -- node -e '...'`. The Node.js code should use `require("dns").resolve("api.anthropic.com", (err, addr) => { ... })` -- print resolved addresses on success, exit 1 on error. Capture the exit code and pass to `run_test`. Use single quotes for the outer `node -e '...'` argument to avoid shell interpolation issues.

8. **Test 2: HTTPS egress to external endpoint.** Execute via `kubectl exec`. The Node.js code should use `require("https").get("https://api.anthropic.com", ...)` with a 10-second timeout. Any HTTP response (even 401) is a pass. Timeout or connection error is a fail.

9. **Test 3: Ingress via localhost.** Use `curl -s -o /dev/null -w "%{http_code}" --max-time 10 localhost/health`. Expected: HTTP 200. Capture the status code and check.

10. **Test 4: Non-allowed egress blocked.** Execute via `kubectl exec`. The Node.js code should attempt `require("http").get("http://example.com:80", ...)` with a 5-second timeout. The test PASSES if the connection times out or errors (ETIMEDOUT, ECONNREFUSED, timeout). The test FAILS if the connection succeeds (gets any HTTP response).

11. **Summary:** Print blank line, then "Results: N passed, M failed". Exit with FAILED count as exit code (0 = all pass).

**Quoting rules:** Use single quotes for the outer `node -e '...'` argument. Inside the JavaScript, use double quotes for strings. This avoids shell variable interpolation and quoting conflicts.

**Make the file executable:** `chmod +x scripts/verify-networkpolicy.sh`.
