- Preserve all other fields (gateway section, token, comments) exactly as-is
- Update the file header comment to note the privacy router routing

**NetworkPolicy (networkpolicy.yaml):**

Remove the LiteLLM egress rule block (lines referencing nemoclaw namespace and port 4000). The rule to remove is:

```yaml
    - to:
        - namespaceSelector:
            matchLabels:
              kubernetes.io/metadata.name: nemoclaw
          podSelector:
            matchLabels:
              app.kubernetes.io/name: litellm-proxy
      ports:
        - protocol: TCP
          port: 4000
```

Keep all other egress rules intact:
- DNS (port 53 UDP+TCP to kube-system)
- OpenShell gateway gRPC (port 8080 to openshell namespace)
- HTTPS egress (port 443 to 0.0.0.0/0)

After removal, the `openclaw-allow` egress section has exactly 3 rules (DNS, gRPC, HTTPS). The HTTPS egress on 443 is belt-and-suspenders with the supervisor proxy -- kept as defense-in-depth.

Do NOT modify the `openclaw-deny-all` NetworkPolicy or the ingress section.
