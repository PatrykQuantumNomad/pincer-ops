<task type="auto">
  <name>Task 2: Validate deletion protection on root Application</name>
  <files></files>
  <action>
Verify the root Application has all three deletion safeguards:

1. Check NO finalizers on root app:
   `kubectl get application root -n argocd -o jsonpath='{.metadata.finalizers}'`
   - Expected: empty or null (no finalizers)

2. Check prune is false:
   `kubectl get application root -n argocd -o jsonpath='{.spec.syncPolicy.automated.prune}'`
   - Expected: false

3. Check preserveResourcesOnDeletion is true:
   `kubectl get application root -n argocd -o jsonpath='{.spec.syncPolicy.preserveResourcesOnDeletion}'`
   - Expected: true

4. (Destructive test -- perform carefully) Delete the root Application NON-CASCADE and verify children survive:
   `kubectl delete application root -n argocd --cascade=orphan`
   Wait 5 seconds.
   `kubectl get application argocd-self -n argocd`
   - Expected: argocd-self still exists (NOT deleted)
   `kubectl get appprojects infrastructure workloads -n argocd`
   - Expected: both AppProjects still exist

5. Re-apply root Application to restore state:
   `kubectl apply -f bootstrap/root-app.yaml`
   Verify root app is recreated: `kubectl get application root -n argocd`

NOTE: The `--cascade=orphan` flag on `kubectl delete` ensures Kubernetes does not garbage-collect owned resources. Combined with the Application having no ArgoCD finalizer, this safely tests that deletion of root does not cascade through ArgoCD's deletion mechanism.
  </action>
  <verify>
Root app has no finalizers, prune: false, preserveResourcesOnDeletion: true.
After root app deletion, argocd-self and AppProjects survive.
Root app is successfully re-applied after deletion test.
  </verify>
  <done>
Root Application deletion protection is verified: no finalizers, prune disabled, preserveResourcesOnDeletion active. Deleting root does not cascade-delete child resources. Root can be re-applied from Git.
  </done>
</task>
