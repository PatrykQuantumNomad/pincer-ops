**bootstrap/root-app.yaml:**
- apiVersion: argoproj.io/v1alpha1, kind: Application
- metadata.name: root, namespace: argocd
- NO finalizers (GOPS-03 deletion protection)
- NO sync-wave annotation (root is applied manually, not discovered)
- spec.project: default (root uses default project for bootstrapping)
- spec.source.repoURL: `https://github.com/OWNER/pincer-ops.git` (placeholder -- actual org TBD)

- syncPolicy.automated.selfHeal: true, prune: false (GOPS-03)
- syncOptions: ServerSideApply=true, CreateNamespace=false
- preserveResourcesOnDeletion: true (GOPS-03 -- must be set at creation time)
- Add comment explaining why no finalizers and why prune is false

**bootstrap/argocd-cm.yaml:**
- apiVersion: v1, kind: ConfigMap
- metadata.name: argocd-cm, namespace: argocd
- Labels: app.kubernetes.io/name: argocd-cm, app.kubernetes.io/part-of: argocd
- data.application.resourceTrackingMethod: "annotation+label" (GOPS-05)
- data.resource.customizations.health.argoproj.io_Application: Lua health check script (GOPS-02)
  - The Lua script checks obj.status.health.status, defaults to "Progressing"
  - Use the BASIC version (health-only, not health+sync) per research recommendation
- Add comments explaining why this ConfigMap must be applied BEFORE root-app

**bootstrap/argocd-self.yaml:**
- apiVersion: argoproj.io/v1alpha1, kind: Application
- metadata.name: argocd-self, namespace: argocd
- annotations: argocd.argoproj.io/sync-wave: "-10", argocd.argoproj.io/manifest-generate-paths: .
- finalizers: resources-finalizer.argocd.argoproj.io (child app CAN have cascade delete)
- spec.project: infrastructure (uses the infrastructure AppProject)
- Same source as root-app (repoURL, targetRevision, path: bootstrap, directory.recurse: true)
- destination: https://kubernetes.default.svc, namespace: argocd
- syncPolicy.automated: selfHeal: true, prune: true
- syncOptions: ServerSideApply=true, CreateNamespace=false

**bootstrap/projects/infrastructure.yaml:**

  <action>
Extend the existing `scripts/bootstrap.sh` to add ArgoCD installation AFTER the existing KIND cluster steps (after the "Bootstrap complete" log line -- replace that final log line so it comes after all steps including ArgoCD).

Add these variables near the top of the script (after sourcing common.sh and KIND_CONFIG):
```
ARGOCD_VERSION="v3.3.1"
ARGOCD_INSTALL_URL="https://raw.githubusercontent.com/argoproj/argo-cd/${ARGOCD_VERSION}/manifests/install.yaml"
BOOTSTRAP_DIR="${SCRIPT_DIR}/../bootstrap"
```

After the existing Step 4 (ConfigMap), add:

**Step 5: Install ArgoCD**
- Use `kubectl create namespace argocd --dry-run=client -o yaml | kubectl apply -f -` (idempotent namespace creation, same pattern as existing ConfigMap step)
- The namespace create pipe needs the same inline verbose handling as the ConfigMap pipe in Step 4 (cannot use run_cmd because it suppresses stdout needed by the pipe)
- Use `run_cmd kubectl apply -n argocd --server-side --force-conflicts -f "${ARGOCD_INSTALL_URL}"` to install ArgoCD
- Log: "ArgoCD ${ARGOCD_VERSION} installed"

**Step 6: Apply ArgoCD configuration (BEFORE root app)**
- Use `run_cmd kubectl apply -n argocd -f "${BOOTSTRAP_DIR}/argocd-cm.yaml"` to apply the ConfigMap
- Add a comment: "# CRITICAL: argocd-cm must be applied BEFORE root-app -- Lua health check enables sync waves"
- Log: "ArgoCD configuration applied"

**Step 7: Wait for ArgoCD readiness**
- Wait for argocd-server: `run_cmd kubectl wait --for=condition=available deployment/argocd-server -n argocd --timeout=120s`
- Wait for argocd-repo-server: `run_cmd kubectl wait --for=condition=available deployment/argocd-repo-server -n argocd --timeout=120s`
- Wait for argocd-application-controller StatefulSet: `run_cmd kubectl rollout status statefulset/argocd-application-controller -n argocd --timeout=120s`
- Log: "ArgoCD is ready"

**Step 8: Apply root Application**
- Use `run_cmd kubectl apply -f "${BOOTSTRAP_DIR}/root-app.yaml"` to create the root Application
- Log: "Root Application created -- ArgoCD will now manage all child Applications"

**Final output:**

- Print how to get the admin password: `kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath="{.data.password}" | base64 -d`
