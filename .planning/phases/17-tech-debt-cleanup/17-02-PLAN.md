  <action>
    Replace the `${CLUSTER_PROVIDER} get clusters 2>/dev/null | grep -q` pipe pattern with a variable-capture pattern in all 4 scripts. The fix captures the provider command output into a variable first, then greps the variable. This avoids SIGPIPE when `grep -q` exits before the provider command finishes.

    **scripts/bootstrap.sh** (around line 69):
    Replace:
    ```bash
    if ${CLUSTER_PROVIDER} get clusters 2>/dev/null | grep -q "^${CLUSTER_NAME}$"; then
      CLUSTER_EXISTS=true
    fi
    ```
    With:
    ```bash
    CLUSTER_LIST=$( ${CLUSTER_PROVIDER} get clusters 2>/dev/null || true )
    if echo "${CLUSTER_LIST}" | grep -q "^${CLUSTER_NAME}$"; then
      CLUSTER_EXISTS=true
    fi
    ```

    **scripts/teardown.sh** (around line 63):
    Replace:
    ```bash
    if ${CLUSTER_PROVIDER} get clusters 2>/dev/null | grep -q "^${CLUSTER_NAME}$"; then
    ```
    With:
    ```bash
    CLUSTER_LIST=$( ${CLUSTER_PROVIDER} get clusters 2>/dev/null || true )
    if echo "${CLUSTER_LIST}" | grep -q "^${CLUSTER_NAME}$"; then
    ```

    **scripts/setup-mcp.sh** (around line 72):
    Replace:
    ```bash
    if ! ${CLUSTER_PROVIDER} get clusters 2>/dev/null | grep -q "^${CLUSTER_NAME}$"; then
    ```
    With:
    ```bash
    CLUSTER_LIST=$( ${CLUSTER_PROVIDER} get clusters 2>/dev/null || true )
    if ! echo "${CLUSTER_LIST}" | grep -q "^${CLUSTER_NAME}$"; then
    ```

    **scripts/verify-networkpolicy.sh** (around line 62):
    Replace:
    ```bash
    if ! ${CLUSTER_PROVIDER} get clusters 2>/dev/null | grep -q "^${CLUSTER_NAME}$"; then
    ```
    With:
    ```bash
    CLUSTER_LIST=$( ${CLUSTER_PROVIDER} get clusters 2>/dev/null || true )
    if ! echo "${CLUSTER_LIST}" | grep -q "^${CLUSTER_NAME}$"; then
    ```

    The `|| true` after the provider command prevents `set -e` from aborting when the provider binary is not found or returns an error (matching the behavior of the original `2>/dev/null`). The `echo "${CLUSTER_LIST}" | grep -q` is safe because `echo` always completes before `grep -q` reads, so no SIGPIPE.

    Also check for any other `get clusters.*| grep` patterns in these files that might need the same treatment (there should be none beyond the ones listed).
