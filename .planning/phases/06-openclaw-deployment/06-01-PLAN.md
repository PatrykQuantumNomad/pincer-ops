Create the directory `workloads/openclaw/base/` and all six manifest files.

**statefulset.yaml:** StatefulSet named `openclaw-gateway` in namespace `openclaw`.
- `serviceName: openclaw-gateway`, `replicas: 1`
- Labels: `app.kubernetes.io/name: openclaw-gateway` on selector, template metadata, and StatefulSet metadata
- Container `openclaw-gateway` with image `ghcr.io/openclaw/openclaw:2026.2.19`, `imagePullPolicy: IfNotPresent`
- Command: `["node", "dist/index.js", "gateway", "--bind", "lan", "--port", "18789"]` -- CRITICAL: `--bind lan` makes gateway listen on 0.0.0.0, without this the Service cannot reach the pod (loopback only)
- Ports: `containerPort: 18789`, name `gateway`, protocol TCP
- Env vars from SealedSecret (unsealed as `openclaw-credentials`):
  - `OPENCLAW_GATEWAY_TOKEN` via `secretKeyRef` (name: openclaw-credentials, key: OPENCLAW_GATEWAY_TOKEN)
  - `ANTHROPIC_API_KEY` via `secretKeyRef` (name: openclaw-credentials, key: ANTHROPIC_API_KEY)
  - `NODE_ENV` hardcoded value `"production"`
  - `HOME` hardcoded value `"/home/node"`
- Volume mounts (ORDER MATTERS -- PVC first, then subPath):
  1. `name: data`, `mountPath: /home/node/.openclaw` (PVC mount)
  2. `name: config`, `mountPath: /home/node/.openclaw/openclaw.json`, `subPath: openclaw.json`, `readOnly: true` (ConfigMap subPath mount -- this places the file INTO the PVC directory without shadowing it)
- Resources: requests 256Mi/250m, limits 1Gi/1000m
- Liveness probe: exec command `["node", "dist/index.js", "health", "--timeout", "5000"]`, initialDelaySeconds 30, periodSeconds 30, timeoutSeconds 10, failureThreshold 3
- Readiness probe: same exec command, initialDelaySeconds 15, periodSeconds 10, timeoutSeconds 10, failureThreshold 3
- Volumes section: `config` volume from configMap `openclaw-config`
- `volumeClaimTemplates`: one template named `data`, accessModes `ReadWriteOnce`, storage `20Gi`

**service.yaml:** Service named `openclaw-gateway` in namespace `openclaw`.
- Type `ClusterIP`
- Labels: `app.kubernetes.io/name: openclaw-gateway`
- Port: 18789, targetPort `gateway`, protocol TCP, name `gateway`
- Selector: `app.kubernetes.io/name: openclaw-gateway`

**configmap.yaml:** ConfigMap named `openclaw-config` in namespace `openclaw`.
- Data key `openclaw.json` with JSON content:
  ```json
  {
    "gateway": {
      "port": 18789,
      "auth": {
        "mode": "token"
      }
    },
    "agents": {
      "defaults": {
        "model": "anthropic/claude-sonnet-4-20250514"
      }
    }
  }
  ```
- Use standard JSON (not JSON5) for ConfigMap safety

**sealed-secret.yaml:** Create a SealedSecret by running `kubeseal` against the cluster.
- First, create a temporary plaintext Secret YAML with:
  - name: `openclaw-credentials`, namespace: `openclaw`
  - stringData: `OPENCLAW_GATEWAY_TOKEN: "dev-token-placeholder"`, `ANTHROPIC_API_KEY: "sk-ant-placeholder-key"`
- Seal it: `kubeseal --format yaml --namespace openclaw --name openclaw-credentials < /tmp/openclaw-secret.yaml > workloads/openclaw/base/sealed-secret.yaml`
- Delete the plaintext temp file immediately after sealing
- If kubeseal is not available or cluster is not running, create a PLACEHOLDER sealed-secret.yaml with a comment explaining it must be re-sealed against a running cluster. Use this template:
  ```yaml
  # PLACEHOLDER: Must be re-sealed against a running cluster with kubeseal
  # kubeseal --format yaml --namespace openclaw --name openclaw-credentials < secret.yaml > sealed-secret.yaml
  apiVersion: bitnami.com/v1alpha1
  kind: SealedSecret
  metadata:
    name: openclaw-credentials
    namespace: openclaw
  spec:
    encryptedData:
      OPENCLAW_GATEWAY_TOKEN: PLACEHOLDER_MUST_RESEAL
      ANTHROPIC_API_KEY: PLACEHOLDER_MUST_RESEAL
    template:
      metadata:
        name: openclaw-credentials
        namespace: openclaw
      type: Opaque
  ```

**httproute.yaml:** HTTPRoute named `openclaw-gateway` in namespace `openclaw`.
