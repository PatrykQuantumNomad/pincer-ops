    2. Create bootstrap/argocd-rbac-cm.yaml -- a NEW ConfigMap (separate from argocd-cm):
       ```yaml
       apiVersion: v1
       kind: ConfigMap
       metadata:
         name: argocd-rbac-cm
         namespace: argocd
         labels:
           app.kubernetes.io/name: argocd-rbac-cm
           app.kubernetes.io/part-of: argocd
       data:
         policy.csv: |
           g, mcp-readonly, role:readonly
         policy.default: ""
       ```
       This is a standard ArgoCD RBAC ConfigMap. ArgoCD looks for this specific name. It assigns the built-in role:readonly to the mcp-readonly account, granting read access to all applications. policy.default is empty to keep non-assigned users locked out.

<task type="auto">
  <name>Task 2: Create .mcp.json and setup script</name>
  <files>.mcp.json, scripts/setup-mcp.sh</files>
  <action>
    1. Create .mcp.json at the project root with this exact content:
       ```json
       {
         "mcpServers": {
           "kubernetes": {
             "command": "npx",
             "args": ["-y", "mcp-server-kubernetes@3.2.0"],
             "env": {
               "ALLOW_ONLY_READONLY_TOOLS": "true",
               "MASK_SECRETS": "true"
             }
           },
           "argocd": {
             "command": "npx",
             "args": ["-y", "argocd-mcp@0.5.0"],
             "env": {
               "ARGOCD_BASE_URL": "${ARGOCD_BASE_URL:-https://localhost:8080}",
               "ARGOCD_API_TOKEN": "${ARGOCD_API_TOKEN}",
               "MCP_READ_ONLY": "true",
               "NODE_TLS_REJECT_UNAUTHORIZED": "0"
             }
           }
         }
       }
       ```
       CRITICAL: Do NOT put actual tokens in this file. The ${ARGOCD_API_TOKEN} syntax uses Claude Code's env var expansion. NODE_TLS_REJECT_UNAUTHORIZED=0 is required because ArgoCD on KIND uses a self-signed certificate. Both servers pin exact versions to prevent unexpected changes.

    2. Create scripts/setup-mcp.sh with these behaviors:
       - Verify the KIND cluster (openclaw-dev) is running via `kind get clusters`
       - Verify kubectl context is `kind-openclaw-dev`, switch if not
       - Start a background `kubectl port-forward svc/argocd-server -n argocd 8080:443`
       - Wait for port-forward to be ready (retry curl against localhost:8080 with --insecure)
       - Retrieve ArgoCD admin password from `argocd-initial-admin-secret`
       - Login via `argocd login localhost:8080 --insecure --username admin --password $PW`
       - Generate token via `argocd account generate-token --account mcp-readonly`
       - Kill the port-forward background process
       - Print clear instructions for the user: export ARGOCD_API_TOKEN and ARGOCD_BASE_URL, remind about port-forward requirement for ongoing use
       - Use `set -euo pipefail` and trap for cleanup (kill port-forward on exit)
       - Follow the same script style as bootstrap.sh (log_step/log_info helper pattern or simple echo with clear headers)
       - Make the script executable (chmod +x)

    Note: Do NOT add the .mcp.json to .gitignore -- it is safe to commit because it contains no secrets (only env var references). It is the project-scoped configuration that all operators share.
  </action>
