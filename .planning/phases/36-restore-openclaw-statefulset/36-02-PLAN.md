    Add two new sections to bootstrap.sh (per RST-06):

    **1. Namespace creation -- insert BEFORE Step 9 (Apply root Application), AFTER Step 8c (cert-manager readiness).**
    Add a new step that creates the `openclaw` namespace idempotently using the same SIGPIPE-safe pattern as the argocd namespace in Step 6:
    ```
    # Step 8d: Create openclaw namespace (before root-app so ArgoCD finds it)
    log_step "Creating openclaw namespace..."
    OC_NS_YAML=$(kubectl create namespace openclaw --dry-run=client -o yaml)
    if [ "${VERBOSE}" = true ]; then
      echo "${OC_NS_YAML}" | kubectl apply -f -
    else
      echo "${OC_NS_YAML}" | kubectl apply -f - >/dev/null 2>&1
    fi
    log_info "openclaw namespace ready"
    ```
    Place this between the cert-manager ClusterIssuer section and Step 9.

    **2. OpenClaw deployment wait -- insert at the END, BEFORE the "Done" banner section.**
    Add a new step that waits for the OpenClaw StatefulSet to become Ready. Use the same polling pattern as other bootstrap steps but adapted for StatefulSet (not Deployment):
    ```
    # Step 16: Wait for OpenClaw Gateway
    log_step "Waiting for OpenClaw Gateway..."
    OC_WAIT=0
    OC_TIMEOUT=300
    until kubectl get statefulset openclaw-gateway -n openclaw >/dev/null 2>&1; do
      if [ ${OC_WAIT} -ge ${OC_TIMEOUT} ]; then
        log_warn "OpenClaw StatefulSet not created after ${OC_TIMEOUT}s (ArgoCD may still be syncing)"
        log_warn "Run 'make status' to check ArgoCD sync state"
        break
      fi
      sleep 5
      OC_WAIT=$((OC_WAIT + 5))
    done
    if kubectl get statefulset openclaw-gateway -n openclaw >/dev/null 2>&1; then
      run_cmd kubectl rollout status statefulset/openclaw-gateway -n openclaw --timeout=300s
      log_info "OpenClaw Gateway is ready"
    fi
    ```
    Use `log_warn` + `break` (not `log_error` + `exit 1`) on timeout because OpenClaw is a workload, not critical infrastructure -- the cluster is functional without it, and ArgoCD will eventually sync it.
    Use `kubectl rollout status statefulset/` (not `kubectl wait --for=condition=available deployment/`) because this is a StatefulSet.
    Use 300s timeout (5min) -- OpenClaw image is ~500MB and first pull takes time.

    **3. Update the Done banner** to include an OpenClaw line:
    After the Secrets line in the banner, add:
    ```
    echo "  OpenClaw:   openclaw namespace (localhost:80 via Envoy Gateway)"
    ```

    Do NOT renumber existing steps. The new namespace step is 8d (sub-step of 8). The deployment wait is Step 16 (next sequential number after Step 15).
