  <action>
Add managedNamespaceMetadata to both workload-openclaw.yaml files (they must remain byte-identical per project convention).

Add the managedNamespaceMetadata block under spec.syncPolicy, BEFORE the existing automated block:
```yaml
syncPolicy:
  managedNamespaceMetadata:
    labels:
      pod-security.kubernetes.io/audit: restricted
      pod-security.kubernetes.io/audit-version: latest
      pod-security.kubernetes.io/warn: restricted
      pod-security.kubernetes.io/warn-version: latest
  automated:
    selfHeal: true
    prune: true
  syncOptions:
    - CreateNamespace=true
```

Do NOT use `enforce` -- the initContainer runs as root (runAsUser: 0), which PSS restricted would reject. The audit+warn mode logs violations without blocking pod creation. This is by design per SEC-04.
