    **STEP 2: BOOTSTRAP KIND**

    Run: `make up PROVIDER=kind`
    (Explicitly selects KIND provider.)

    Expected duration: 5-12 minutes. KIND bootstrap runs the full v1.0 sync wave set:
    - Wave -10: ArgoCD self-management + AppProjects
    - Wave -5: MetalLB
    - Wave -4: Envoy Gateway controller (OCI Helm)
    - Wave -3: Sealed Secrets
    - Wave -2: cert-manager
    - Wave -1: Envoy Gateway DaemonSet + hostPort config
    - Wave +10: OpenClaw

    MONITOR for fallback warnings: Note any "ArgoCD cannot sync from repo" warnings. In KIND mode, ALL infrastructure components are ArgoCD-managed, so fallback usage is more significant than in Kinder mode.

    **STEP 3: POST-BOOTSTRAP STABILIZATION**

    After bootstrap completes, wait up to 180 seconds for ArgoCD to reconcile all 8 Applications (KIND has more sync waves than Kinder, so allow extra time):
    ```
    for i in $(seq 1 36); do
      HEALTH=$(kubectl get applications -n argocd -o jsonpath='{range .items[*]}{.metadata.name}={.status.health.status}{" "}{end}' 2>/dev/null)
      echo "Check $i: $HEALTH"
      ALL_HEALTHY=true
      for app in infra-metallb infra-envoy-gateway infra-envoy-gateway-config infra-sealed-secrets infra-cert-manager workload-openclaw; do
        if ! echo "$HEALTH" | grep -q "${app}=Healthy"; then
          ALL_HEALTHY=false
        fi
      done
      if [ "$ALL_HEALTHY" = "true" ]; then
        echo "All critical apps healthy"
        break
      fi
      sleep 5
    done
    ```

    `kubectl get applications -n argocd`
    Expected Applications: root, argocd-self, infra-metallb, infra-envoy-gateway, infra-envoy-gateway-config, infra-sealed-secrets, infra-cert-manager, workload-openclaw.
    All should show Synced. Health should be Healthy (root and argocd-self may show Progressing -- accepted).

    CHECK 3 -- make status:

    All 8 Applications should show sync status.

    CHECK 4 -- OpenClaw health via localhost:

    Expected: 200.
