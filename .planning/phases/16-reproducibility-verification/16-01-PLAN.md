  <action>
    This task modifies NO files. It exercises the existing scripts against a live Kinder cluster.

    **PRE-CHECKS:**

    1. Verify sealing key backup exists (if a cluster was previously running):
       `ls -la ~/.pincer/sealed-secrets-key.yaml`
       If no backup exists AND no cluster is running, that is fine (fresh start).

    2. Check if a cluster is currently running:
       `kinder get clusters 2>/dev/null | grep openclaw-dev || kind get clusters 2>/dev/null | grep openclaw-dev`
       If a cluster exists, proceed with teardown. If not, skip to bootstrap.

    **STEP 1: TEARDOWN (if cluster exists)**

    Run: `make down`
    (Default provider is Kinder; this tears down the Kinder cluster.)

    Verify cluster is gone:
    `kinder get clusters 2>/dev/null | grep openclaw-dev` -- should return nothing.
    `kind get clusters 2>/dev/null | grep openclaw-dev` -- should also return nothing.

    Verify sealing key backup survived teardown:
    `ls -la ~/.pincer/sealed-secrets-key.yaml` -- file should still exist (make down without --clean preserves it).

    Wait 5 seconds for Docker cleanup before proceeding.

    **STEP 2: BOOTSTRAP**

    Run: `make up`
    (Defaults to CLUSTER_PROVIDER=kinder.)

    Expected duration: 3-10 minutes. Monitor for:
    - Kinder cluster creation (1 CP + 2 workers)
    - ArgoCD installation
    - root-app.yaml application
    - Sync wave processing (-10, -3, -1, +10 for Kinder path)

    MONITOR for fallback warnings: If you see "ArgoCD cannot sync from repo" warnings, note them but let bootstrap complete.

    **STEP 3: POST-BOOTSTRAP STABILIZATION**

    After bootstrap completes, wait up to 120 seconds for ArgoCD to reconcile:
    ```
    for i in $(seq 1 24); do
      HEALTH=$(kubectl get applications -n argocd -o jsonpath='{range .items[*]}{.metadata.name}={.status.health.status}{" "}{end}' 2>/dev/null)
      echo "Check $i: $HEALTH"
      ALL_HEALTHY=true
      for app in infra-envoy-gateway-config infra-sealed-secrets workload-openclaw; do
        if ! echo "$HEALTH" | grep -q "${app}=Healthy"; then
          ALL_HEALTHY=false
        fi
      done
      if [ "$ALL_HEALTHY" = "true" ]; then
        echo "All critical apps healthy"
        break
      fi
      sleep 5
    done
    ```

    **STEP 4: VERIFICATION CHECKS**

    CHECK 1 -- ArgoCD Applications (Kinder expects exactly 5):
    `kubectl get applications -n argocd`
    Expected Applications: root, argocd-self, infra-envoy-gateway-config, infra-sealed-secrets, workload-openclaw.
    All should show Synced. Health should be Healthy (root and argocd-self may show Progressing -- this is accepted per Phase 8 precedent).
    MUST NOT have: infra-metallb, infra-envoy-gateway, infra-cert-manager (these are Kinder addons, not ArgoCD apps).

    CHECK 2 -- make doctor:
    `make doctor`
    Must exit 0. Should check 4 components: ArgoCD server, Envoy Gateway DaemonSet, Sealed Secrets controller, OpenClaw StatefulSet.

    CHECK 3 -- make status:
    `make status`
    All 5 Applications should show sync status.

    CHECK 4 -- OpenClaw health via localhost:
    `curl -s -o /dev/null -w "%{http_code}" http://localhost/health`
    Expected: 200.
    If curl fails, check pod status: `kubectl get pods -n openclaw -l app=openclaw-gateway`
    Pod should be Running 1/1.

    CHECK 5 -- NetworkPolicy enforcement:
    `make verify-netpol`
    Expected: All tests pass (4/4).

    CHECK 6 -- SealedSecrets key lifecycle:
    `kubectl get secret -n kube-system -l sealedsecrets.bitnami.com/sealed-secrets-key=active -o name`
    Must return at least one secret (key was restored from backup).
    `ls -la ~/.pincer/sealed-secrets-key.yaml` -- backup should have recent timestamp.

    CHECK 7 -- make check (manifest validation + test suite):
    `make check`
    All 116 BATS tests should pass. kubeconform validation should pass.

    **RECORD RESULTS:**
    Create a structured summary of all 7 checks with PASS/FAIL status.
