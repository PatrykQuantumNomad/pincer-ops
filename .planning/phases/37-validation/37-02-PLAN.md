  <action>
Run the full cluster lifecycle to verify end-to-end:

1. Tear down any existing cluster: `make down`
2. Bootstrap fresh Kinder cluster: `make up` (Kinder is default provider)
3. Wait for bootstrap to complete (all 16 steps)
4. Run `make doctor` to check cluster health
5. Run `make status` to verify ArgoCD application sync state

If `make up` fails at any step, capture the error output and diagnose. Common issues:
- Port 80/443 conflict: check `lsof -i :80` and `lsof -i :443`
- Docker not running: check `docker info`
- Kinder binary missing: check `which kinder`

If bootstrap succeeds but ArgoCD apps are not healthy, check:
- `make status` for app sync status
- `kubectl get pods -A` for pod states
- `kubectl logs -n openclaw -l app=openclaw-gateway` for OpenClaw issues
