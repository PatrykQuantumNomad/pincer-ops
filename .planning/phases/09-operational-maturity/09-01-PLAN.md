<task type="auto">
  <name>Task 1: Create GitHub Actions manifest validation workflow and script</name>
  <files>
    .github/workflows/validate-manifests.yml
    scripts/validate-manifests.sh
  </files>
  <action>
Create `scripts/validate-manifests.sh` -- a reusable shell script that validates all manifests in the repo. Structure:
- Set `set -euo pipefail`, track exit code via EXIT_CODE variable
- Define SCHEMA_LOCATION pointing to datreeio/CRDs-catalog URL template: `https://raw.githubusercontent.com/datreeio/CRDs-catalog/main/{{.Group}}/{{.ResourceKind}}_{{.ResourceAPIVersion}}.json`
- Set K8S_VERSION to 1.32.0
- Define `validate_raw()` function: runs `kubeconform -summary -output text -kubernetes-version $K8S_VERSION -schema-location default -schema-location $SCHEMA_LOCATION -skip CustomResourceDefinition` on a directory
- Define `validate_kustomize()` function: runs `kustomize build $dir | kubeconform` with same flags (no -skip CRD since kustomize output won't contain raw CRDs)
- Call `validate_raw "bootstrap/" "bootstrap"` for raw Application/AppProject manifests
- Call `validate_kustomize "workloads/openclaw/overlays/dev" "openclaw/dev"` for the OpenClaw overlay
- For infrastructure bases with ONLY local resources (metallb, envoy-gateway), call `validate_kustomize`. For bases that reference remote URLs (sealed-secrets, cert-manager), SKIP kustomize build to avoid downloading 50MB+ upstream manifests and hitting rate limits. Instead, just validate the local Application YAML files.
- Exit with EXIT_CODE (non-zero if any validation failed)
- Make the script executable (chmod +x)

Create `.github/workflows/validate-manifests.yml`:
- Trigger: `pull_request` on `branches: [main]` with `paths:` filter for `bootstrap/**`, `infrastructure/**`, `workloads/**`, `cluster/**`
- Single job `validate` on `ubuntu-latest`
- Steps: (1) `actions/checkout@v4`, (2) `yokawasa/action-setup-kube-tools@v0.11.2` with `setup-tools: |` containing kustomize and kubeconform, versions `kustomize: '5.7.1'` and `kubeconform: '0.7.0'`, (3) run `./scripts/validate-manifests.sh`

IMPORTANT: The infrastructure bases for sealed-secrets and cert-manager use `resources: - https://github.com/...` remote URLs. Do NOT run kustomize build on those -- it downloads large upstream manifests and is flaky in CI. Only validate local manifests and overlays.
  </action>

Confirm the script references the correct overlay paths that exist in the repo.
  </verify>
  <done>

<task type="auto">
  <name>Task 2: Create pre-commit hook and installer for plaintext Secret detection</name>
  <files>
    scripts/hooks/pre-commit
    scripts/hooks/install-hooks.sh
  </files>
  <action>
Create `scripts/hooks/pre-commit`:
- Shebang: `#!/usr/bin/env bash`
- Comment header explaining purpose: reject commits containing plaintext Kubernetes Secrets
- `set -euo pipefail`
- Get staged YAML files: `STAGED_FILES=$(git diff --cached --name-only --diff-filter=ACM -- '*.yaml' '*.yml' 2>/dev/null)`
- Early exit if no staged YAML files
- Loop through each staged file, run `grep -qE '^\s*kind:\s*Secret\s*$' "$file"` -- this pattern matches `kind: Secret` exactly but NOT `kind: SealedSecret` because SealedSecret has more characters after Secret
- On match, print error with file name and guidance to use kubeseal
- Track FOUND_SECRETS boolean, exit 1 if any found with helpful message
- Make executable (chmod +x)

Create `scripts/hooks/install-hooks.sh`:
- Shebang: `#!/usr/bin/env bash`
- `set -euo pipefail`
- Resolve SCRIPT_DIR and REPO_ROOT
- Copy `pre-commit` from scripts/hooks/ to `.git/hooks/pre-commit`
- chmod +x the installed hook
- Print success message with bypass instructions (`git commit --no-verify`)
- Make executable (chmod +x)

Test the pre-commit hook logic by creating a temporary file with `kind: Secret` and verifying the grep pattern catches it, then test with `kind: SealedSecret` and verify it does NOT match.
  </action>
  <verify>
Run `bash -n scripts/hooks/pre-commit` and `bash -n scripts/hooks/install-hooks.sh` for syntax validation. Test the grep pattern: `echo 'kind: Secret' | grep -qE '^\s*kind:\s*Secret\s*$' && echo "MATCH"` should print MATCH. Test negative: `echo 'kind: SealedSecret' | grep -qE '^\s*kind:\s*Secret\s*$' || echo "NO MATCH"` should print NO MATCH. Verify both files are executable.
  </verify>
  <done>
Pre-commit hook at `scripts/hooks/pre-commit` rejects commits containing `kind: Secret` (plaintext) without false-positiving on `kind: SealedSecret`. Installer at `scripts/hooks/install-hooks.sh` copies the hook into `.git/hooks/`. Both scripts are executable with proper shebang lines.
  </done>
