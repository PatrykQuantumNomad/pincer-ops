## Tech Debt

### Phase 15: Developer Experience

1. **Makefile env propagation gap** — `setup-mcp` and `verify-netpol` targets call scripts directly without `CLUSTER_PROVIDER=$(CLUSTER_PROVIDER)` prefix. The Make-variable form `make verify-netpol CLUSTER_PROVIDER=kind` doesn't propagate. **Workaround:** Use shell env var form `CLUSTER_PROVIDER=kind make verify-netpol` (standard and documented pattern). **Severity:** Low.

2. **REQUIREMENTS.md tracking** — DX-04 and DX-05 checkboxes not checked. Work is complete but the tracking artifact was not updated. **Severity:** Trivial.

### Phase 13: Conditional ArgoCD Architecture

3. **Stale comment in shared file** — `bootstrap/kinder/infra-envoy-gateway-config.yaml` line 7 references "Depends on infra-envoy-gateway (wave -4) being healthy first" which doesn't apply to kinder path. Cannot fix in kinder copy alone because BATS test 12 enforces byte-identity between provider copies. Options: (a) remove comment from both copies, or (b) accept inaccuracy. **Severity:** Low (cosmetic, no functional impact).

### Phase 16: Reproducibility Verification

4. **Test count discrepancy** — CLAUDE.md and Makefile reference 116 BATS tests; actual count is 115 (105 unit + 10 integration). Off by 1 due to a test consolidation. **Severity:** Trivial.

5. **Flaky BATS test** — "bootstrap.sh with kinder skips MetalLB and Envoy GW controller steps" intermittently fails under `make check` (pipe race condition in mock) but passes consistently when run standalone. Pre-existing, not a regression. **Severity:** Low.
