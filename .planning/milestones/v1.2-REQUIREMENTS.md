## v1.2 Requirements

Requirements for NemoClaw governance-only deployment. LiteLLM Proxy replaces the non-existent standalone OpenShell governance images. Each requirement maps to roadmap phases.

### Governance Infrastructure

- [x] **GOV-01**: LiteLLM proxy deployed as a Deployment in `nemoclaw` namespace with health probes -- Phase 19
- [x] **GOV-02**: LiteLLM Service exposes port 4000 as ClusterIP within `nemoclaw` namespace -- Phase 19
- [x] **GOV-03**: LiteLLM ConfigMap provides model routing configuration (NVIDIA NIM, OpenAI, Anthropic providers) -- Phase 19
- [x] **GOV-04**: NVIDIA_API_KEY managed as SealedSecret and mounted only in LiteLLM pod -- Phase 19
- [x] **GOV-05**: ArgoCD Application (`infra-nemoclaw`) at sync wave 0 in both `bootstrap/kind/` and `bootstrap/kinder/` -- Phase 18
- [x] **GOV-06**: `nemoclaw` namespace created with Kustomize base/overlay structure under `infrastructure/nemoclaw/` -- Phase 18

### OpenClaw Integration

- [x] **INT-01**: OpenClaw `openclaw.json` ConfigMap updated with `models.providers` routing through LiteLLM -- Phase 21
- [x] **INT-02**: OpenClaw pod does NOT have NVIDIA_API_KEY environment variable -- credential isolation enforced -- Phase 21

### Network Security

- [x] **NET-01**: OpenClaw NetworkPolicy modified: egress to LiteLLM proxy in nemoclaw namespace allowed -- Phase 21
- [x] **NET-02**: OpenClaw NetworkPolicy modified: direct HTTPS egress (443) restricted to messaging platforms only -- Phase 21
- [x] **NET-03**: LiteLLM NetworkPolicy: default-deny + allow ingress from openclaw namespace, DNS egress, HTTPS egress -- Phase 19

### Security Hardening

- [x] **SEC-01**: OpenClaw StatefulSet has `readOnlyRootFilesystem: true` with explicit writable mounts -- Phase 20
- [x] **SEC-02**: OpenClaw and LiteLLM pods have `seccompProfile.type: RuntimeDefault` and `capabilities.drop: ["ALL"]` -- Phase 20
- [x] **SEC-03**: `nemoclaw` namespace has PSS label `pod-security.kubernetes.io/enforce: restricted` -- Phase 18
- [x] **SEC-04**: `openclaw` namespace has PSS labels `audit` + `warn` (not `enforce`) -- Phase 20

### CI and Validation

- [x] **CI-01**: `make validate` runs kubeconform against NemoClaw infrastructure manifests -- Phase 22
- [x] **CI-02**: BATS tests verify LiteLLM manifest structure (Deployment, Service, ConfigMap, NetworkPolicy) -- Phase 22
- [x] **CI-03**: BATS tests verify OpenClaw NetworkPolicy blocks direct LLM API egress -- Phase 22
