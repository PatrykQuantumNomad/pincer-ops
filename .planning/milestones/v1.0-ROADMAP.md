# Milestone v1.0: MVP

**Status:** SHIPPED 2026-02-20
**Phases:** 1-11
**Total Plans:** 20

## Overview

Pincer Ops v1.0 delivers a fully GitOps-managed Kubernetes platform for deploying and operating OpenClaw on KIND. Built in 11 phases following the infrastructure dependency chain, the platform is fully reproducible from a single `kubectl apply -f bootstrap/root-app.yaml`. All 33 requirements satisfied. Audit passed with tech debt only (no blockers).

## Milestone Summary

**Key Decisions:**

- KIND for local cluster (production-fidelity without cloud costs)
- ArgoCD App of Apps with single root Application entry point
- Gateway API (Envoy Gateway) instead of ingress-nginx (skipped migration path)
- StatefulSet for OpenClaw (stable storage identity for file-backed monolith)
- Bitnami SealedSecrets over SOPS/External Secrets (simpler GitOps workflow)
- Kustomize over Helm (declarative overlays without template complexity)
- MCP integration in v1 (AI-assisted ops from day one)
- DaemonSet with hostPort for macOS/KIND localhost access
- Two-Application pattern for Envoy Gateway (Helm controller + kustomize config)
- Exec-based probes for OpenClaw health checks

**Issues Resolved:**

- containerPort values corrected to 10080/10443 (Envoy Gateway internal mapping)
- V8 heap OOM at 1Gi limit — increased to 2Gi
- workloads AppProject clusterResourceWhitelist updated for Namespace (CreateNamespace=true)
- Placeholder repoURL replaced with real GitHub URL in Phase 8
- Stale comments and bootstrap inconsistencies cleaned up in Phase 11

**Issues Deferred:**

- argocd-self/root circular dependency shows Progressing permanently (cosmetic)
- Webhook URL localhost:9999 placeholder (one-line swap for production)
- hostPath backup storage (backups lost on KIND teardown, acceptable for dev)
- Manual pre-commit hook installation (developer workstation setup, not cluster infra)

**Technical Debt Incurred:**

- PVC backup and sealing key backup use hostPath volumes (ephemeral on teardown)
- Pre-commit hook requires manual `scripts/hooks/install-hooks.sh` run
- Remote kustomize bases skipped in CI validation (flaky 50MB+ downloads)
