# Milestone v2.0: OpenShell Sandbox

**Status:** SHIPPED 2026-03-21
**Phases:** 23-29
**Total Plans:** 17

## Overview

Replace LiteLLM-based governance approximation with real OpenShell/NemoClaw deployment -- OpenShell gateway, agent-sandbox CRD controller, OpenClaw as Sandbox CR with kernel-level isolation (Landlock, seccomp-BPF, network namespaces) and privacy router inference routing.

## Milestone Summary

**Key Decisions:**
- Static Sandbox CR (ArgoCD-managed) preserves GitOps invariant -- root-app.yaml can reconstruct full state
- DaemonSet + hostPath for supervisor binary -- declarative, ArgoCD-managed, no custom images needed
- Fresh PVC start for v2.0 -- avoids migration complexity; OpenClaw re-onboards
- openshell AppProject groups both namespaces (openshell, agent-sandbox-system) as single security boundary
- Sync wave 0 for namespace apps, wave 2 for CRD controller, wave 3 for supervisor DaemonSet, wave 5 for gateway, wave 10 for sandbox CR
- Namespace PSS labels applied via patch (not resource) to avoid Kustomize duplicate with upstream manifest
- Gateway manifests in separate Kustomize root (infrastructure/openshell/gateway/) -- no namespace field due to cluster-scoped RBAC
- Pod-scoped NetworkPolicy in shared namespace; HTTPRoute targets controller-created Service
- hostPath type Directory on sandbox (DaemonSet wave 3 guarantees existence before sandbox wave 10)
- RuntimeDefault seccomp stays -- supervisor applies seccomp-BPF internally
- Kept HTTPS egress (443) as defense-in-depth alongside supervisor proxy
- PSS privileged on openshell namespace: deliberate tradeoff, supervisor enforces isolation internally
- Root CA in cert-manager ns (ClusterIssuer requirement); SealedSecret placeholder with re-seal instructions
- Full CRD schema extraction for local kubeconform validation (schemas/{group}/{kind}_{version}.json)
- openshell-client-tls ca.crt for client CA volume (avoids separate secret)

**Issues Resolved:**
- Stale bootstrap directory file count tests updated across phases 25, 26, 27
- Stale test paths in nemoclaw-manifests.bats and validate-manifests.bats fixed in phase 26
- Stale nemoclaw/litellm sync wave map comments cleaned from 10 bootstrap YAML files in phase 28
- Replaced SAND-07 TLS-disabled tests with SEC-01 mTLS-enabled assertions in phase 29
- Added 3 missing files to shared_files parity array in phase 29

**Issues Deferred:**
- Phase 28 runtime verification (end-to-end inference via inference.local) -- approved by user, pending cluster stabilization
- Landlock `hard_requirement` mode deferred -- current `best_effort` mode sufficient for dev
- SandboxTemplate, SandboxClaim, SandboxWarmPool deferred to v3+
- GPU-enabled sandbox deferred to v3+

**Technical Debt Incurred:**
- SealedSecret placeholder values need real keys sealed post-bootstrap
- PSS privileged on openshell namespace (supervisor requires root for kernel isolation)
- Landlock in best_effort mode (not hard_requirement)
- Phase 28 runtime verification not completed (inference.local end-to-end)
